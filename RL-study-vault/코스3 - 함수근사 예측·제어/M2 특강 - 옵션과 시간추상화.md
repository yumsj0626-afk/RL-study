## 핵심 개념 정리

### 에이전트가 필요한 두 가지 지식

| 종류 | 정의 | 예시 |
| :--- | :--- | :--- |
| **절차적 지식 (Procedural)** | 무언가를 하는 방법 | 정책(Policy), 스킬, 특정 객체 조작법 |
| **예측적/경험적 지식 (Predictive/Empirical)** | 에이전트의 행동 조건 하에 무슨 일이 일어날지 | 가치 함수, 모델 |

좋은 지식 표현의 세 가지 조건:
- **학습 가능성**: 데이터로 획득할 수 있어야 함
- **표현력**: 다양한 상황에 대해 풍부하게 표현 가능해야 함
- **조합성**: 기존 지식을 조합해 더 큰 지식을 구성할 수 있어야 함

---

### 왜 시간 단위 추상화가 필요한가

기본 MDP에서 행동은 항상 **한 타임스텝** 동안만 지속됩니다. 하지만 현실 문제에서는 에이전트가 긴 시간에 걸친 행동 계획이 필요합니다.

몬트리올 → 에드먼턴 이동 예시:
- **근육 단위** 계획: 수천 개의 미세 동작 → 너무 길고 비효율
- **행동 단위** 계획: 택시 타기 → 비행기 타기 → 택시 타기 (4단계) → 효율적이고 재사용 가능

> 추상화된 행동(스킬)은 계획을 극적으로 단축시키고, 다른 상황(에드먼턴 대신 토론토 이동)에서도 동일하게 재사용됩니다.

---

### 옵션 (Options) 프레임워크

옵션은 시간적으로 확장된 행동을 형식화한 개념입니다. 세 가지 구성 요소로 정의됩니다.

```
옵션 = (개시 집합, 내부 정책, 종료 조건)
```

| 구성 요소 | 정의 | 예시 (공항 게이트로 걷기) |
| :--- | :--- | :--- |
| **개시 집합 (Initiation Set)** | 옵션을 시작할 수 있는 상태의 집합 | 공항 안에 있을 때 |
| **내부 정책 (Internal Policy)** | 옵션 실행 중 기본 행동을 선택하는 정책 $\pi(a\|s)$ | 걷는 동작 |
| **종료 조건 (Termination Condition)** | 상태별 옵션 종료 확률 (확률적) | 게이트 도달 또는 비상경보 발생 시 |

---

### 옵션 모델

각 옵션은 자체 모델을 가집니다.
- **기대 보상**: 옵션 실행 중 누적 기대 보상
- **전이 분포**: 옵션 종료 시 도달할 상태와 **소요 시간의 결합 분포** (옵션마다 지속 시간이 다르기 때문)

옵션이 주어지면 에이전트는 일반 MDP와 유사하게 추론하지만, 지속 시간이 고정되지 않은 **반-마르코프 결정 과정(Semi-MDP)**에서 동작합니다. 마르코프 속성은 유지됩니다.

> 좋은 소식: 기존 알고리즘(가치 반복, TD 학습 등)이 Semi-MDP에서도 거의 동일하게 작동합니다.

## 미해결 연구 문제

| 문제 | 설명 |
| :--- | :--- |
| 상태 추상화 + 시간 추상화 결합 | 둘을 동시에 잘 하는 방법은 여전히 연구 중 |
| 좋은 옵션 발견 문제 | 어떤 종료 조건이 좋은 옵션을 만드는지 자동으로 찾는 방법 미해결 |

## 강의 내용과의 연결
