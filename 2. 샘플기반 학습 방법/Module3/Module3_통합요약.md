## 전체 흐름 한눈에 보기

```
Dynamic Programming (Course 1)
    └─ 환경 모델 필요, 전체 상태 반복 계산
    
Monte Carlo (Module 2)
    └─ 모델 불필요, 에피소드 완료 후 업데이트
    
Temporal Difference (Module 3)
    └─ 모델 불필요 + 에피소드 완료 전에도 업데이트 가능
       = DP의 bootstrapping + MC의 model-free 학습
```

TD는 DP와 MC의 장점만 결합한 방법론입니다.
이 모듈은 TD가 왜 필요한지, 실제로 얼마나 잘 작동하는지, 그리고 어디서 왔는지를 다룹니다.

## 1. TD의 핵심 아이디어 — 매 스텝마다 배운다

### DP / MC / TD 비교

| 특성 | Dynamic Programming | Monte Carlo | TD |
| :--- | :---: | :---: | :---: |
| 환경 모델 필요 | ✅ | ❌ | ❌ |
| 경험에서 직접 학습 | ❌ | ✅ | ✅ |
| 에피소드 완료 전 업데이트 | ✅ | ❌ | ✅ |
| Bootstrapping | ✅ | ❌ | ✅ |

### TD 업데이트 수식

$$V(S_t) \leftarrow V(S_t) + \alpha \left[ R_{t+1} + \gamma V(S_{t+1}) - V(S_t) \right]$$

대괄호 안의 항이 **TD 오차**입니다. 다음 상태의 추정값 $V(S_{t+1})$을 현재 업데이트에 재사용하는 것이 bootstrapping의 핵심입니다.

MC 업데이트와의 비교:

$$V(S_t) \leftarrow V(S_t) + \alpha \left[ G_t - V(S_t) \right]$$

MC는 실제 return $G_t$를 타겟으로 쓰기 때문에 에피소드가 끝나야 합니다.
TD는 다음 상태의 추정값으로 타겟을 만들기 때문에 매 스텝 즉시 업데이트합니다.

### 퇴근길 운전 예시

각 지점에서의 잔여 시간 예측이 상태 가치에 해당합니다.

| 상태 | 예측 잔여 시간 | 실제 소요(보상) |
| :--- | :--- | :--- |
| 사무실 출발 | 30분 | 5분 |
| 주차장 탈출 (비 시작) | 35분 | 15분 |
| 고속도로 탈출 | 15분 | 30분 |
| 느린 트럭 구간 | 10분 | 10분 |
| 집 근처 진입 | 3분 | 3분 |

**MC**: 집에 도착(43분)해야 비로소 모든 상태를 업데이트합니다.

**TD**: 고속도로를 예상보다 빨리 탈출한 순간, 그 정보가 즉시 이전 상태 추정값에 반영됩니다.

$$V(\text{주차장}) \leftarrow 35 + \alpha[15 + 15 - 35] = 30\text{분}$$

> 새로운 정보가 생기는 순간 바로 배운다는 것이 TD의 본질입니다. 완벽한 결과를 기다리지 않아도 됩니다.

## 2. TD vs MC 실험 비교 — 5-state Random Walk

### 실험 환경

- 상태 A~E (5개), 시작: C, 종료: 양 끝
- 오른쪽 종료 시 +1, 나머지 0, $\gamma = 1$
- 각 상태의 참 가치 = 오른쪽으로 종료할 확률

| 상태 | A | B | C | D | E |
| :--- | :---: | :---: | :---: | :---: | :---: |
| 참 가치 | 1/6 | 2/6 | 3/6 | 4/6 | 5/6 |

초기값 0.5로 설정, 100번 독립 실행 평균.

### 첫 에피소드에서의 차이

- **TD**: C → D 전이에서 TD 오차 = 0 + 0.5 - 0.5 = 0. 초기값이 모두 같으면 종료 직전 상태(E)만 업데이트됨
- **MC**: 에피소드가 끝난 후 방문한 모든 상태를 한꺼번에 업데이트

### 수렴 속도 비교 결과

x축: 에피소드 수 / y축: RMSE (낮을수록 좋음)

- TD가 **모든 $\alpha$ 값에서 일관되게 MC를 앞섬**
- $\alpha$가 클수록 빠르게 수렴하지만 최종 오차 증가
- $\alpha$가 작을수록 느리지만 낮은 최종 오차

> 특정 파라미터 조합의 우연이 아니라, bootstrapping 구조 자체의 이점입니다. 매 스텝의 새로운 정보를 즉시 활용하는 것이 수렴 속도의 차이를 만듭니다.

## 3. 역사적 맥락 — Andy Barto & Rich Sutton 대담

### 강화학습이 "없던 시절"

1980년 이전까지 강화학습은 독립적인 연구 분야로 존재하지 않았습니다.
50~60년대 AI 연구자들이 보상 개념을 언급했지만 결국 supervised learning으로 흡수되었고, 이 패턴은 이후 AI 파동에서도 반복되었습니다.

Barto와 Sutton이 문헌을 뒤졌을 때 "보상 신호를 최적화하기 위한 학습"을 연구한 사람이 거의 없었습니다.

### Trial and Error vs Error Correction

강화학습 역사에서 반복된 핵심 혼동입니다.

| 구분 | 방식 | 해당 분야 |
| :--- | :--- | :--- |
| Error correction | 정답을 알고 그 방향으로 수정 | Supervised Learning |
| Trial and error | 결과(보상)를 보고 행동을 조정 | Reinforcement Learning |

Sutton은 이 혼동이 현재 논문에서도 반복된다고 지적했습니다.

### TD 학습의 기원

TD는 행동주의 심리학(behaviorism)에서 영감을 받았습니다.
행동주의는 당시 AI 커뮤니티에서 가장 비인기적인 분야였고, Barto는 오히려 그 덕분에 "남들이 공부하지 않은 것을 알고 있다"는 비밀 무기를 갖게 되었다고 표현했습니다.

이후 신경과학에서 도파민 시스템이 TD 오차와 유사하게 작동한다는 것이 발견되면서 TD는 뇌과학과도 연결됩니다.

### 내재적 동기(Intrinsic Motivation)

외부 보상(논문 인용, 유행하는 분야)이 없던 시절에도 연구를 계속할 수 있었던 이유는 주제 자체가 흥미로웠기 때문입니다.

> 동물은 생존 문제가 없는 여유로운 시간에 다양한 스킬을 익힙니다. 당장 쓸모가 없어 보여도. 그리고 실제 문제가 생겼을 때 그 스킬들이 해결의 도구가 됩니다. 기초 연구의 가치와 맞닿아 있는 원리입니다.
