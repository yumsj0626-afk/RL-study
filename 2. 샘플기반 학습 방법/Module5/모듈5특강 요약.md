
# Model-based Reinforcement Learning 핵심 정리

## 1. 한 줄 요약

Model-based RL은 로봇이 실제 환경에서 무작정 시행착오를 하기 전에, 모델을 이용해 미래를 예측하고 더 나은 행동을 선택하게 만드는 방식이다.

## 2. 전체 요약

이 스크립트는 자율주행, 드론, 로봇 제어 같은 현실 로봇 문제에서 왜 Model-based Reinforcement Learning이 중요한지 설명한다. 로봇은 현실에서 직접 시행착오를 많이 하기 어렵다. 자동차가 사고를 내면서 배우거나, 드론이 계속 추락하면서 배우는 방식은 비용도 크고 위험하다. 그래서 환경의 작동 방식을 모델로 만들고, 그 모델 안에서 가능한 미래를 예측하며 행동을 결정한다.

특히 자율주행처럼 복잡한 환경에서는 단순 규칙만으로 의사결정을 만들기 어렵다. 보행자, 차량, 자전거, 도로 상황이 계속 바뀌고, 행동 역시 단순한 선택지가 아니라 속도, 조향각, 가속도처럼 연속적인 값으로 이루어져 있다. 따라서 현실 로봇 문제에서는 모델과 함수 근사를 이용한 계획 방식이 중요해진다.

## 3. 핵심 개념

| 개념 | 의미 |
|---|---|
| Model | 현재 상태와 행동을 입력하면 다음 상태와 비용을 예측하는 함수 |
| Model-based RL | 모델을 이용해 미래를 예측하고, 실제 행동 전에 계획하는 강화학습 방식 |
| Sample Complexity | 좋은 성능을 얻기 위해 실제 환경과 몇 번 상호작용해야 하는지를 나타내는 개념 |
| Continuous State/Action | 위치, 속도, 조향각처럼 값이 연속적으로 변하는 상태와 행동 |
| Quadratic Value Function Approximation | 가치함수를 2차식으로 근사해 연속 행동에서도 최적 행동을 계산하는 방식 |
| Differential Dynamic Programming | 모델과 비용 함수를 근사하고, Bellman equation을 이용해 뒤에서부터 최적 정책을 계산하는 방법 |

## 4. 핵심 인사이트

### 4.1 로봇 문제는 현실적으로 Model-based가 될 수밖에 없다

Q-learning, Sarsa, TD처럼 경험에서 직접 배우는 방식은 개념적으로 중요하다. 하지만 현실 로봇에서는 시행착오 자체가 비싸고 위험하다. 자율주행차가 실제 도로에서 수많은 사고를 내며 배우거나, 로봇이 계속 망가지면서 학습하는 방식은 현실적이지 않다. 그래서 모델, 시뮬레이터, 동역학 예측, 비용 함수가 필요하다.

### 4.2 모델은 로봇의 ‘상상력’에 가깝다

사람도 행동하기 전에 머릿속으로 결과를 예측한다. 예를 들어, 깨지기 쉬운 물건을 한 손으로 들면 떨어질 가능성을 상상하고 행동을 조심하게 된다. Model-based RL도 비슷하다. 모델을 통해 “이 행동을 하면 다음에 어떤 일이 생길까?”를 미리 계산하고, 그 결과를 기준으로 행동을 선택한다.

### 4.3 현실 문제에서는 완벽한 해보다 좋은 근사가 중요하다

자율주행이나 헬리콥터 제어 같은 문제는 너무 복잡해서 모든 상황을 정확히 계산하기 어렵다. 그래서 현재 상황 근처에서 모델을 선형으로 근사하고, 가치함수를 2차식으로 근사해 빠르게 좋은 행동을 찾는다. 이 방식은 완벽한 전체 해를 찾기보다, 실제 의사결정에 필요한 수준의 좋은 근사를 빠르게 얻는 데 초점이 있다.

## 5. Model-free와 Model-based 비교

| 구분 | Model-free RL | Model-based RL |
|---|---|---|
| 핵심 방식 | 경험에서 직접 가치나 정책을 학습 | 환경 모델을 이용해 미래를 예측하고 계획 |
| 대표 예시 | TD, Sarsa, Q-learning | Dynamic Programming, Dyna, Differential Dynamic Programming |
| 장점 | 모델이 없어도 학습 가능 | 실제 시행착오를 줄일 수 있음 |
| 단점 | 많은 경험이 필요할 수 있음 | 좋은 모델을 만드는 것이 어렵거나 비용이 큼 |
| 적합한 상황 | 환경과 많이 상호작용할 수 있는 문제 | 실제 시행착오가 비싸거나 위험한 로봇 문제 |

## 6. 보고서용 문장

Model-based reinforcement learning is useful in robotics because real-world trials are expensive, slow, and sometimes dangerous. A model allows the agent to predict future states and costs before acting, reducing the number of real interactions needed. This is especially important in continuous control problems such as autonomous driving, drones, and robotic manipulation.

한국어로 정리하면, 모델 기반 강화학습은 실제 시행착오가 비싸고 위험한 로봇 문제에서 중요하다. 모델은 현재 상태와 행동이 다음 상태와 비용으로 어떻게 이어지는지 예측하게 해주며, 에이전트는 이를 이용해 실제로 행동하기 전에 가능한 미래를 계획할 수 있다.

## 7. 내가 가져갈 포인트

강화학습을 공부할 때 모든 알고리즘을 철학적으로 깊게 파고들기보다, 어떤 문제 상황에서 왜 그 방식이 필요한지를 먼저 이해하는 것이 중요하다. Model-free 방식은 경험에서 직접 배우는 방식이고, Model-based 방식은 모델을 통해 미래를 예측하고 계획하는 방식이다. 현실 로봇처럼 실제 시행착오가 위험하거나 비싼 문제에서는 Model-based 접근이 특히 중요하다.

## 8. 최종 결론

Model-based RL은 로봇이 직접 다치거나 실패하면서 배우는 대신, 모델을 이용해 머릿속 시뮬레이션을 먼저 해보고 행동하게 만드는 방식이다.
