# Part 1: Feature Construction for Linear Methods

### Coarse Coding

---

## 한 줄 요약

테이블(one-hot) → 상태 집계(비겹침 영역) → **Coarse Coding(겹침 허용 영역)** 순서로 일반화되는 선형 함수 근사 특징 표현을 소개합니다.

---

## 핵심 개념 정리

### 표현 방식의 진화

| 방식 | 특징 벡터 형태 | 겹침 허용 | 연속 상태 대응 |
| :--- | :--- | :--- | :--- |
| 테이블 (one-hot) | 상태마다 1개 특징이 1 | 불가 | 불가 (무한 상태 시 파탄) |
| 상태 집계 | 그룹마다 1개 특징이 1 | 불가 (간격·겹침 없음) | 가능 (근사) |
| Coarse Coding | 여러 특징이 동시에 활성화 | **가능** | 가능 |

물고기가 연못(2D 연속 상태)을 헤엄치는 예시: 테이블로는 무한한 위치 각각에 항목을 만들 수 없습니다.

---

### Coarse Coding이란

임의 모양(원, 타원, 사각형 등)의 영역들을 **겹쳐서** 상태 공간을 덮는 방식입니다.

- **수용 영역(Receptive Field)**: 해당 특징을 활성화시키는 위치들의 집합
- 특징 $i$ = 현재 상태가 $i$번 원 안에 있으면 1, 아니면 0

상태가 이동하면 다른 원들의 조합이 활성화됩니다. 인접한 상태는 비슷한 활성화 패턴을 가지지만, 동시에 활성화되는 특징의 개수나 구성이 달라질 수 있습니다.

> 상태 집계는 "영역이 겹치지 않아야 한다"는 제약이 있습니다. Coarse Coding은 그 제약을 제거해 더 유연한 표현을 허용합니다.

---

## 이전 내용과의 연결 / 다음으로 이어지는 흐름

특징 벡터를 만드는 새로운 방법인 Coarse Coding을 도입했습니다. 다음 영상에서는 원의 크기·모양·개수가 **일반화와 분별**에 어떤 영향을 미치는지 구체적으로 다룹니다.

---

### Generalization Properties of Coarse Coding

---

## 한 줄 요약

수용 영역의 크기·모양·개수가 각각 **일반화 속도**와 **분별 정확도**에 어떻게 영향을 미치는지, 두 속성 간의 트레이드오프를 다룹니다.

---

## 핵심 개념 정리

### 크기 → 일반화 범위

한 상태에서 가중치를 업데이트하면, 활성화된 특징들의 수용 영역 합집합에 속하는 **모든 상태**의 가치 추정이 영향을 받습니다.

- 큰 원 → 수용 영역 합집합이 넓음 → **넓은 일반화**, 적은 샘플로 빠른 학습
- 작은 원 → 수용 영역 합집합이 좁음 → **좁은 일반화**, 더 많은 샘플 필요

---

### 모양 → 일반화 방향

원이 아닌 **수직으로 긴 타원**을 쓰면, 업데이트가 주로 수직 방향으로 퍼집니다. 특징의 모양으로 **어느 방향으로 일반화할지를 제어**할 수 있습니다.

---

### 겹침 → 분별 능력

두 상태가 **완전히 동일한 특징 벡터**를 가지면, 두 상태를 구별할 수 없습니다. 서로 다른 특징 벡터를 갖는 영역의 크기가 작을수록 분별 능력이 높아집니다.

- 원을 많이 쓰거나 작게 만들면 → 겹침 교차 영역이 작아짐 → **분별 능력 향상**
- 분별 향상은 곧 장기적 근사 정확도 향상으로 이어짐

> 1D 단계 함수 예시: 짧은 구간(small interval) 50개 → 분별 좋지만 초기 학습 느림. 긴 구간(large interval) 50개 → 초기 학습 빠르고 최종 정확도도 높았음. 과제마다 이상적인 설정이 다르며, 단일 해법은 없습니다.

---

## 비교 / 정리 표

| 파라미터 | 크게/많이 | 작게/적게 |
| :--- | :--- | :--- |
| 원의 크기 | 일반화 넓음, 학습 빠름 | 일반화 좁음, 학습 느림 |
| 원의 개수 | 분별 향상, 메모리 증가 | 분별 저하, 메모리 절약 |
| 원의 모양 (타원) | 특정 방향 일반화 강조 | 방향 무관 (원형) |

---

## 이전 내용과의 연결 / 다음으로 이어지는 흐름

Coarse Coding의 일반화·분별 특성을 이해했습니다. 다음 영상에서는 Coarse Coding의 계산 효율적인 특수 사례인 **Tile Coding**을 소개합니다.

---

### Tile Coding

---

## 한 줄 요약

**Tile Coding**은 균일한 격자(tiling)를 여러 겹 겹쳐 놓는 Coarse Coding의 특수 사례입니다. 계산이 효율적이면서도 일반화와 분별을 잘 조절할 수 있습니다.

---

## 핵심 개념 정리

### Tiling이란

상태 공간을 정사각형(혹은 직사각형) 격자로 완전히 분할하는 것을 **Tiling**이라고 합니다. Tiling 하나만 쓰면 상태 집계와 동일합니다.

---

### 여러 Tiling을 겹쳐 분별 향상

여러 Tiling을 조금씩 **오프셋(offset)**을 두고 겹쳐 배치합니다.

```
Tiling 1:  |  A  |  B  |  C  |  D  |
Tiling 2:    |  a  |  b  |  c  |  d  |
Tiling 3:      |  α  |  β  |  γ  |  δ  |
```

오프셋 덕분에 각 상태의 특징 벡터가 고유해지며, **교차 영역이 작아져 분별 능력이 향상**됩니다.

- 1개 Tiling → 사각형 안에서만 일반화 (상태 집계와 동일)
- 여러 Tiling → 대각선 방향으로 일반화, 분별 향상

---

### 직사각형으로 차원별 일반화 조절

차원마다 스케일을 다르게 적용하면 격자가 직사각형이 됩니다. 이를 통해 **각 차원의 일반화 폭을 독립적으로 조절**할 수 있습니다.

---

### 계산 효율성과 한계

- **장점**: 격자가 균일하므로 현재 상태가 어느 셀에 있는지 빠르게 계산 가능. 저차원 환경에서 예비 실험에 이상적.
- **한계**: 차원 수가 늘어날수록 타일 수가 **기하급수적으로 증가** (차원의 저주). 차원을 독립적으로 타일링해야 할 수도 있지만, 이 경우 교차 특성을 포착하지 못합니다.

---

## 이전 내용과의 연결 / 다음으로 이어지는 흐름

Tile Coding의 구조를 이해했습니다. 다음 영상에서는 이를 실제 TD 학습에 연결하고, 상태 집계와 성능을 비교합니다.

---

### Using Tile Coding in TD

---

## 한 줄 요약

Tile Coding의 **희소 이진 특징 벡터**를 활용하면 가치 함수 계산을 효율적으로 할 수 있고, 실험에서 상태 집계보다 분별 능력이 우수함을 확인합니다.

---

## 핵심 개념 정리

### 희소 이진 벡터의 효율적 계산

선형 함수에서 $\hat{v}(s, \mathbf{w}) = \mathbf{x}(s)^\top \mathbf{w}$를 계산할 때, Tile Coding의 특징 벡터는 대부분이 0입니다.

따라서 내적을 전체 벡터 연산으로 하지 않고, **활성화된 타일에 해당하는 가중치만 합산**하면 됩니다.

$$\hat{v}(s, \mathbf{w}) = \sum_{i \in \text{active tiles}} w_i$$

활성 타일 수는 모든 상태에서 항상 일정하므로(= tiling 개수), 계산 시간이 고정됩니다.

---

### 1,000개 상태 랜덤 워크 실험

| 방식 | 파라미터 | 스텝 크기 $\alpha$ |
| :--- | :--- | :--- |
| 상태 집계 | 5개 그룹 (그룹당 200 상태) | $\alpha / 1$ |
| Tile Coding | 50개 Tiling, 타일 크기 200 상태 (각 Tiling 6개 타일) | $\alpha / 50$ |

- 두 방식 모두 초기 학습 속도는 비슷 (강한 일반화 덕분)
- 그러나 Tile Coding이 **더 낮은 가치 오차로 수렴** (작은 교차 영역 덕에 분별 향상)
- Tile Coding의 파라미터 수가 훨씬 많지만 학습 속도가 뒤처지지 않음

> 흥미로운 점: 파라미터 수가 많아도 학습 속도가 줄지 않는 이유는, 50개 Tiling이 동시에 업데이트되어 각 스텝의 정보를 풍부하게 활용하기 때문입니다.

---

## 이전 내용과의 연결 / 다음으로 이어지는 흐름

Tile Coding은 **사전에 설계된 고정 특징**입니다. 다음 영상부터는 특징을 **데이터로부터 학습**하는 신경망을 다룹니다.

# Part 2: Neural Networks

---

### What is a Neural Network?

---

## 한 줄 요약

신경망은 노드(node)와 연결(connection)로 이루어진 **파라미터화된 함수**입니다. 데이터가 입력층에서 출력층으로 순방향으로 흐르며 비선형 변환을 거쳐 가치 추정값을 생성합니다.

---

## 핵심 개념 정리

### 구조

- **노드(Node)**: 입력을 받아 계산을 수행하는 단위
- **연결(Connection)**: 노드 간 정보 전달, 각 연결에 가중치 $w$ 부여
- **레이어(Layer)**: 노드들의 집합. 입력층 → 은닉층(들) → 출력층

**Feedforward 신경망**: 데이터가 항상 앞 방향으로만 흐름. 역방향 연결이 있으면 순환 신경망(RNN).

---

### 각 노드의 계산

$$\text{output} = f\left( \sum_i w_i \cdot \text{input}_i \right)$$

- $f$: **활성화 함수 (Activation Function)** — 비선형 변환 담당

| 활성화 함수 | 수식 | 특징 |
| :--- | :--- | :--- |
| tanh | $\tanh(x)$ | 출력 $[-1, 1]$ |
| 로지스틱 | $\frac{1}{1+e^{-x}}$ | 출력 $[0, 1]$ |
| ReLU | $\max(0, x)$ | 계산 빠름, 희소 활성화 |
| 임계값 | $\mathbb{1}[x > 0]$ | 이진 출력 |

---

### 레이어 전체를 행렬 연산으로

입력 벡터 $\mathbf{s}$, 가중치 행렬 $W$:

$$\mathbf{h} = f(W \cdot \mathbf{s})$$

레이어 출력 벡터 $\mathbf{h}$는 다음 레이어의 입력이 됩니다. 이 과정이 최종 출력층까지 반복됩니다.

---

## 이전 내용과의 연결 / 다음으로 이어지는 흐름

신경망이 파라미터화된 함수임을 이해했습니다. 다음 영상에서는 신경망이 **어떻게 특징을 구성하는지**, Tile Coding과 무엇이 다른지를 비교합니다.

---

### Non-linear Approximation with Neural Networks

---

## 한 줄 요약

신경망의 은닉층은 입력을 **비선형 특징으로 변환**하는 역할을 하며, 이 특징들이 Tile Coding과 유사하지만 **데이터로부터 학습된다**는 점이 결정적 차이입니다.

---

## 핵심 개념 정리

### 신경망을 특징 구성기로 보기

각 은닉 노드 = 하나의 특징 = **입력의 비선형 함수**

- 각 노드는 서로 다른 가중치를 가지므로 서로 다른 특징을 생성
- 은닉층 전체 출력 = **새로운 표현(representation)**
- 이 표현에 선형 가중합을 적용 → 최종 가치 추정

---

### Tile Coding vs 신경망 비교

| 속성 | Tile Coding | 신경망 |
| :--- | :--- | :--- |
| 특징 구성 방식 | 사전 설계 (고정) | 데이터로 학습 (가변) |
| 수용 영역 형태 | 직사각형 (하드 경계) | 복잡한 비선형 형태 (부드러운 경계) |
| 도메인 지식 필요 | 타일 크기·개수·오프셋 설계 필요 | 레이어 수·노드 수 설계만 필요 |
| 특징 개선 가능 | 불가 | 학습 중 지속적으로 개선 |

---

### 학습된 특징의 시각화

2D 연속 공간(좁은 통로가 있는 환경)에서 학습한 신경망의 특징 하나를 시각화하면:
- 수용 영역이 복잡한 비선형 형태
- 어떤 방향으로는 활성화가 강하고 다른 방향으로는 약함 (방향별 일반화 정도 다름)
- 여러 특징이 합쳐져 벽의 위치 같은 환경 구조를 자연스럽게 포착

> 흥미로운 점: 신경망 특징들의 수용 영역을 모아보면, 환경의 벽 위치가 자연스럽게 드러납니다. 도메인 지식 없이도 유용한 구조를 학습합니다.

---

## 이전 내용과의 연결 / 다음으로 이어지는 흐름

신경망이 특징을 학습하는 방식을 이해했습니다. 다음 영상에서는 레이어를 깊게 쌓으면 어떤 이점이 있는지, **깊이(depth)**의 역할을 설명합니다.

---

### Deep Neural Networks

---

## 한 줄 요약

신경망을 깊게 쌓으면 **조합(composition)**과 **추상화(abstraction)**를 통해 복잡한 함수를 더 효율적으로 표현할 수 있습니다.

---

## 핵심 개념 정리

### 깊이와 보편 근사 정리

단일 은닉층 신경망도 이론적으로 **어떤 연속 함수든 근사**할 수 있습니다 (보편 근사 정리, Universal Approximation Property). 하지만 실용적으로는 깊은 망이 복잡한 함수를 더 효율적으로 표현합니다.

---

### 조합을 통한 특징 구성

깊은 망에서 각 레이어는 이전 레이어의 출력을 조합해 더 복잡한 특징을 만듭니다.

```
입력: 원시 픽셀
  └─ 1층: 선(edge), 다양한 각도의 직선
      └─ 2층: 선들의 조합 → 다양한 형태
          └─ 3층: 형태들의 조합 → 물체/동물
              └─ 출력: 고수준 판단 (예: 고양이 여부)
```

모듈식 구조: 레이어를 추가·제거·교체해 유연하게 설계 가능.

---

### 추상화

연속된 레이어를 지나며 불필요한 세부 정보가 제거되고 핵심 개념만 남습니다.

**Bottleneck Layer**: 레이어마다 노드 수를 점차 줄여, 가장 좁은 레이어에 핵심 표현을 압축합니다. 이 레이어 이후로는 예측에 필요한 정보만 남습니다.

> 다만 실제로 좋은 아키텍처를 선택하는 것은 여전히 어려운 문제입니다. 이 수업에서는 구체적인 아키텍처 설계는 다루지 않습니다.

---

| 특성 | 얕은 망 (1 은닉층) | 깊은 망 (다중 은닉층) |
| :--- | :--- | :--- |
| 이론적 표현력 | 충분 (보편 근사) | 충분 |

# Part 3: Training Neural Networks

### Gradient Descent for Training Neural Networks

---

## 한 줄 요약

역전파(Backpropagation)는 단순히 **경사 하강법**입니다. 출력에서 시작해 레이어를 거슬러 올라가며 효율적으로 그래디언트를 계산하는 것이 핵심 아이디어입니다.

---

## 핵심 개념 정리

### 표기

| 기호 | 의미 |
| :--- | :--- |
| $\mathbf{s}$ | 입력 (상태) |
| $A$ | 입력 → 은닉층 가중치 행렬 |
| $\mathbf{x}$ | 은닉층 출력 (학습된 특징) |
| $B$ | 은닉층 → 출력 가중치 행렬 |
| $\hat{y}$ | 최종 출력 (가치 추정) |
| $L$ | 손실 함수 (예: 제곱 오차) |

$$\boldsymbol{\psi} = \mathbf{s} \cdot A, \quad \mathbf{x} = f_A(\boldsymbol{\psi}), \quad \Theta = \mathbf{x} \cdot B, \quad \hat{y} = f_B(\Theta)$$

---

### 그래디언트 유도 (B에 대해)

연쇄 법칙 적용:

$$\frac{\partial L}{\partial B} = \underbrace{\frac{\partial L}{\partial \hat{y}} \cdot f_B'(\Theta)}_{\delta_B} \cdot \mathbf{x}$$

$\delta_B$: 출력층의 오차 신호.

제곱 오차 + 선형 출력 활성화 적용 시:

$$\delta_B = \hat{y} - y, \qquad \frac{\partial L}{\partial B} = \delta_B \cdot \mathbf{x}$$

---

### 그래디언트 유도 (A에 대해)

$A$가 $\mathbf{x}$에도 영향을 미치므로 체인룰 한 단계 더 적용:

$$\delta_A = \delta_B \cdot B \cdot f_A'(\boldsymbol{\psi}), \qquad \frac{\partial L}{\partial A} = \delta_A \cdot \mathbf{s}$$

> 핵심 패턴: 각 레이어의 그래디언트 = **(해당 레이어의 오차 신호 $\delta$) × (해당 레이어의 입력)**. $\delta$는 출력에서 입력 방향으로 전파됩니다.

---

### Backpropagation 의사 코드

```
for 각 데이터 (s, y):
  # Forward Pass
  x    = f_A(s · A)
  y_hat = f_B(x · B)

  # Backward Pass (B)
  δ_B = y_hat - y           # 제곱 오차 + 선형 출력 가정
  grad_B = δ_B · x
  B ← B - α_B · grad_B

  # Backward Pass (A)
  δ_A = δ_B · B · f_A'(s · A)
  grad_A = δ_A · s
  A ← A - α_A · grad_A
```

ReLU 은닉층의 경우 $f_A'(\psi) = \mathbb{1}[\psi > 0]$을 곱합니다. 더 깊은 망에서도 $\delta$를 재귀적으로 역전파하면 동일한 패턴이 반복됩니다.

### Optimization Strategies for Neural Networks

---

## 한 줄 요약

신경망 학습 성능을 높이는 세 가지 실용적 기법을 소개합니다: **적절한 초기화**, **모멘텀**, **가중치별 적응형 스텝 크기**.

---

## 핵심 개념 정리

### 1. 초기화 전략

가중치 초기값이 학습 경로를 결정합니다.

- **나쁜 초기화**: 평탄한 영역(그래디언트 ≈ 0)에서 시작하면 학습이 거의 진행되지 않음
- **좋은 초기화**: 빠르게 좋은 최솟값으로 이동 가능한 위치에서 시작

**실용 전략**: 가중치를 작은 분산의 정규 분포에서 샘플링

$$w \sim \mathcal{N}\left(0,\ \frac{1}{\sqrt{n_{\text{in}}}}\right)$$

- 뉴런마다 다른 초기값 → 다양한 특징 학습 가능 (다양성 확보)
- 작은 분산 → 레이어 간 출력 범위 유사 유지

---

### 2. 모멘텀 (Momentum)

과거 그래디언트의 방향을 누적해 일관된 방향으로 가속하는 기법입니다.

$$\mathbf{m}_t = \lambda \mathbf{m}_{t-1} + \nabla L_t$$
$$\mathbf{w} \leftarrow \mathbf{w} - \alpha \mathbf{m}_t$$

- 같은 방향으로 계속 업데이트 → **모멘텀 축적**, 큰 스텝
- 방향이 엇갈리는 업데이트 → **모멘텀 소멸**, 일반 경사 하강과 유사

> 모멘텀은 이론적으로 정상점 수렴 속도를 가속합니다.

---

### 3. 적응형 스텝 크기 (Adaptive Step Sizes)

하나의 전역 스텝 크기 $\alpha$는 어떤 가중치에는 너무 크고 다른 가중치에는 너무 작을 수 있습니다.

각 가중치마다 별도의 스텝 크기 $\alpha_{t,i}$를 학습 통계에 기반해 적응적으로 조정합니다.

$$\mathbf{w}_i \leftarrow \mathbf{w}_i - \alpha_{t,i} \cdot \frac{\partial L}{\partial w_i}$$

실제 구현체로는 RMSProp, Adam 등이 있습니다 (과제에서 구현 예정).

---

## 비교 / 정리 표

| 기법 | 해결하는 문제 | 핵심 아이디어 |
| :--- | :--- | :--- |
| Xavier 초기화 | 나쁜 시작점 | 작은 분산으로 균형 잡힌 초기화 |
| 모멘텀 | 느린 수렴 | 과거 그래디언트 방향 누적 |
| 적응형 스텝 크기 | 전역 $\alpha$의 한계 | 가중치별 개인화 학습률 |

### David Silver on Deep Learning + RL = AI?

---

## 한 줄 요약

강화학습(RL)은 **문제의 틀**이고, 딥러닝(DL)은 **해결 도구**입니다. 둘을 결합한 Deep RL이 일반 인공지능에 가장 가깝게 가는 레시피라는 주장과 실제 성과를 소개합니다.

---

## 핵심 개념 정리

### 두 분야의 역할

| 분야 | 역할 | 핵심 요소 |
| :--- | :--- | :--- |
| 강화학습 | 문제 정의 | 에이전트-환경, 보상 최대화 |
| 딥러닝 | 해결 도구 | 신경망, 표현 학습, 역전파 |

> "RL + DL = Deep RL" — 이 조합이 인간 수준의 다양한 과제를 해결하는 레시피라는 것이 David Silver의 핵심 주장입니다.

---

### RL 에이전트의 세 구성 요소와 DL 적용

RL 에이전트는 다음 세 가지 중 일부 또는 전부를 가집니다.

| 구성 요소 | 설명 | DL 적용 시 손실 함수 |
| :--- | :--- | :--- |
| 정책 (Policy) | 행동 결정 | Policy Gradient |
| 가치 함수 (Value Function) | 상태 평가 | TD 오차 최소화 |
| 모델 (Model) | 환경 예측 | 다음 상태 예측 오차 최소화 |

학습 알고리즘은 동일: 손실 함수를 정의하고, **경사 하강법**으로 최적화합니다.
