# Module 3 — Constructing Features for Prediction

> Course 3: Prediction and Control with Function Approximation
> 교재 범위: Sutton & Barto Ch. 9.4–9.5.0 (pp. 204–210), 9.5.3–9.5.4 (pp. 215–222), 9.7 (pp. 223–228)

Module 2에서 선형 근사 $\hat{v}(s, \mathbf{w}) = \mathbf{w}^\top \mathbf{x}(s)$ 는 수렴 보장과 효율 덕분에 매력적임을 확인했다. 그러나 그 성패는 **상태를 특징 $\mathbf{x}(s)$ 로 어떻게 표현하느냐**에 결정적으로 달려 있다. 이번 모듈은 (1) 좋은 특징을 **손으로 설계**하는 방법(coarse coding, tile coding)과 (2) 특징을 **자동으로 학습**하는 비선형 근사(신경망)를 다룬다.

특징 선택은 결국 **사전 도메인 지식**을 시스템에 주입하는 작업이다. 직관적으로, 특징은 "일반화가 적절한 상태 공간의 축"에 대응해야 한다. 이동 로봇의 가치를 추정한다면 위치·남은 배터리·최근 소나 측정값 등이 특징 후보가 된다.

## 1. Feature Construction for Linear Methods (도입)

선형 방법의 효율과 일반화 품질은 특징의 질에 달려 있다. 핵심 질문은 "**어떤 상태들 사이에 일반화를 허용할 것인가**"이다.

- 특징은 일반화가 일어나길 원하는 방향(축)에 대응해야 한다.
- 잘못된 특징은 서로 무관한 상태를 묶거나(과한 일반화), 유사한 상태를 분리(일반화 부족)한다.

이번 모듈의 표현들은 모두 **선형 근사의 특징 $\mathbf{x}(s)$ 를 만드는 방법**이며, 학습 알고리즘 자체(식 9.7의 SGD, 9.8의 선형 형태)는 Module 2와 동일하게 유지된다.

> 참고: 교재 9.5.1(Polynomials), 9.5.2(Fourier Basis)도 특징 구성 방법이지만 본 모듈 범위에서는 다루지 않고, 실무에서 더 핵심적인 coarse coding / tile coding으로 바로 넘어간다.

## 2. Coarse Coding

연속 2차원 상태 공간을 생각하자. 상태 공간 위에 여러 개의 **원(circle)** 을 두고, 상태가 어떤 원 안에 있으면 그 특징을 1(**present**), 밖이면 0(**absent**)으로 둔다. 이런 0–1 특징을 **이진 특징(binary feature)** 이라 한다.

어떤 이진 특징들이 켜져 있는지가 "상태가 어떤 원들 안에 있는지"를 나타내며, 따라서 상태 위치를 **거칠게(coarsely)** 부호화한다. 이렇게 겹치는(overlapping) 특징으로 상태를 표현하는 방식이 **coarse coding**이다. (원·이진일 필요는 없다.)

```
[Figure 9.6 위치 표시]
두 상태 s, s'가 공유하는 원(수용 영역)의 개수만큼만 서로 일반화된다.
공통 원이 1개 → 약한 일반화.
```

**수용 영역(receptive field)의 크기·모양이 일반화를 결정한다.**

한 상태(공간상의 한 점)에서 학습하면, 그 점과 교차하는 **모든 원의 가중치**가 영향을 받는다. 식 (9.8)에 의해, 근사 가치 함수는 그 원들의 합집합 안의 모든 상태에서 영향을 받는다 — 공유 원이 많을수록 효과가 크다.

| 원의 크기·모양 | 일반화 형태 | (그림) |
| :--- | :--- | :--- |
| 작은 원 | 좁은 일반화 (가까운 이웃만) | 9.7(left) |
| 큰 원 | 넓은 일반화 (먼 거리까지) | 9.7(middle) |
| 길쭉한 원 | 비대칭 일반화 (한 방향으로) | 9.7(right) |

**핵심 통찰 — 변별력(acuity)은 무엇이 결정하는가?**

큰 수용 영역은 넓게 일반화하지만, 최종 근사가 수용 영역 너비보다 미세한 변별을 못 할 것처럼 보인다. 하지만 그렇지 않다.

- **초기 일반화**: 수용 영역의 크기·모양이 결정한다.
- **궁극적 변별력(acuity)**: 수용 영역 크기가 아니라 **특징의 총 개수**가 결정한다.

```
[Figure 9.8 위치 표시]
1D square-wave 함수를 narrow / medium / broad 세 가지 너비로 학습한 결과.
밀도(약 50개)는 동일.
- 초기: 너비가 큰 영향 (broad는 넓게, narrow는 울퉁불퉁)
- 최종 점근해: 너비의 영향이 미미함
```

**Example 9.3의 결론:** 수용 영역의 모양은 일반화에는 강한 영향을 주지만, 점근 해의 품질에는 거의 영향을 주지 않는다.

## 3. Tile Coding

**Tile coding**은 다차원 연속 공간을 위한 coarse coding의 한 형태로, 유연하면서 계산 효율이 매우 높다. 현대 디지털 컴퓨터에서 가장 실용적인 특징 표현일 수 있다.

**기본 구조:**

- 수용 영역들을 상태 공간의 **분할(partition)** 로 묶는다. 각 분할을 **타일링(tiling)**, 각 원소를 **타일(tile)** 이라 한다.
- 단일 타일링만 쓰면 → 같은 타일 안에서는 완전 일반화, 밖에서는 일반화 없음 → 사실상 **상태 집합(state aggregation)** 과 같아진다.

```
[Figure 9.9 위치 표시]
연속 2D 공간 위에 4개의 타일링을 서로 조금씩 offset 시켜 겹침.
한 점은 각 타일링에서 정확히 1개 타일에 속함 → 4개 특징이 active.
예: 4×4×4 = 64개 성분 중 4개만 1, 나머지는 0.
```

**coarse coding의 강점을 얻으려면 겹치는 수용 영역이 필요하다.** 그러나 한 분할의 타일들은 정의상 겹치지 않는다. 그래서 **여러 타일링을 타일 너비의 일부만큼 서로 offset** 시킨다. 모든 상태는 각 타일링에서 정확히 하나의 타일에 떨어진다.

**Tile coding의 실용적 장점**

1. **활성 특징 수가 항상 일정.** 타일링마다 정확히 1개 특징이 켜지므로, active 특징 총수 = 타일링 개수($n$). 덕분에 스텝 사이즈 $\alpha$ 를 직관적으로 설정할 수 있다.
   - $\alpha = \frac{1}{n}$ → 정확히 **1회 학습(one-trial learning)**: 학습 예제 $s \mapsto v$ 이후 $\hat{v}(s, \mathbf{w}_{t+1}) = v$.
   - 보통은 더 느리게: $\alpha = \frac{1}{10n}$ → 한 번에 목표의 1/10만큼 이동, 이웃 상태는 공유 타일 수에 비례해 더 적게 이동.

2. **이진 특징 → 계산 효율.** 각 성분이 0/1이므로 가중합 $\hat{v}$ 계산이 거의 자명하다. $d$ 번의 곱셈·덧셈 대신, active한 $n \ll d$ 개 특징의 인덱스만 구해 해당 가중치 $n$ 개를 더하면 된다.

```
[Figure 9.10 위치 표시]
1000-state random walk에서 단일 타일링(state aggregation)과
다중 타일링(50 tilings, coarse coding) 학습 곡선 비교.
다중 타일링이 더 낮은 √VE 로 수렴 → coarse coding을 쓰는 이유.
```

**타일링 offset 방향이 일반화에 영향을 준다.**

- **균일(uniform) offset** ($(1,1)$ 변위 벡터): 대각선 방향에 강한 인공물(artifact)이 생기고, 상태에 따라 일반화 형태가 질적으로 달라진다.
- **비대칭(asymmetric) offset** ($(1,3)$ 등): 일반화가 학습 상태 중심으로 더 구형(spherical)·균질하게 형성됨 → 일반적으로 **선호**된다.

```
[Figure 9.11 위치 표시]
8개 타일링. (위) 균일 offset → 대각선 인공물.
(아래) 비대칭 offset → 균질한 일반화.
```

**권장 설계 규칙(Miller & Glanz, 1996):**

- 차원 $k$ 의 연속 공간에서 변위 벡터로 **첫 홀수들** $(1, 3, 5, \dots, 2k-1)$ 사용.
- 타일링 개수 $n$ 은 $4k$ 이상의 2의 거듭제곱으로 설정.
- 예: $k=2$ → $n = 2^3 = 8 \ge 4k$, 변위 $(1,3)$.

**타일 모양에 따른 일반화 제어** — 타일링 전략 선택은 (1) 타일링 개수와 (2) 타일 모양을 정하는 것이다.

| 타일 모양 | 일반화 특성 |
| :--- | :--- |
| 정사각형(square) | 각 차원에 거의 균등하게 일반화 |
| 한 방향으로 늘인 줄무늬(stripe) | 그 차원을 따라 일반화 촉진 |
| 대각선 줄무늬 | 한 대각선 방향으로 일반화 촉진 |
| 불규칙(irregular) | 가능하나 드묾 |

타일링 개수·타일 크기가 점근 근사의 **해상도(resolution)** 를, 타일 모양이 **일반화의 성격**을 결정한다.

## 4. What is a Neural Network? / Nonlinear Function Approximation (9.7)

지금까지의 특징(coarse/tile coding)은 모두 **손으로 설계**한 것이다. **인공 신경망(Artificial Neural Network, ANN)** 은 특징 자체를 학습하는 비선형 함수 근사기다.

**기본 구조 (feedforward ANN):**

- 네트워크에 루프가 없는(피드백 경로 없는) 구조. 입력층 / 은닉층(hidden layer) / 출력층으로 구성.
- 각 연결에 실수 가중치가 있다(생물학적 시냅스 효율에 대응).
- 루프가 있으면 **순환(recurrent) ANN**. 여기서는 단순한 피드포워드만 다룸.

```
[Figure 9.14 위치 표시]
입력 4 / 은닉층 2개 / 출력 2 인 일반적 피드포워드 ANN.
```

**유닛(unit)과 활성화 함수(activation function):**

각 유닛은 입력 신호의 가중합을 계산한 뒤 **비선형 활성화 함수**를 적용한다. 흔히 쓰이는 함수:

$$
\text{logistic (sigmoid):}\quad f(x) = \frac{1}{1 + e^{-x}}
\qquad
\text{rectifier (ReLU):}\quad f(x) = \max(0, x)
$$

계단 함수 $f(x) = 1$ if $x \ge \theta$ else $0$ 은 임계값 $\theta$ 의 이진 유닛이 된다.

**왜 비선형이 필수인가?**

- 은닉층 없는 ANN은 표현 가능한 입출력 함수가 극히 제한적이다.
- 그러나 **하나의 은닉층**에 충분히 많은 sigmoid 유닛이 있으면, 컴팩트 영역의 **임의의 연속 함수**를 원하는 정확도로 근사할 수 있다 (**보편 근사 정리(universal approximation)**, Cybenko 1989).
- 단, 모든 유닛이 선형 활성화면 전체 네트워크가 은닉층 없는 네트워크와 동치가 된다(선형의 선형은 선형). → **비선형성이 본질적**이다.

## 5. Deep Neural Networks & 학습 (9.7 심화)

보편 근사 정리에도 불구하고, 복잡한 AI 과제에는 **깊은(deep) 구조** — 여러 은닉층의 계층적 추상화 — 가 더 쉽고 때로는 필수다. 깊은 층은 점점 더 추상적인 표현을 계산하며, 각 유닛이 전체 입출력 함수의 계층적 표현에 기여하는 **특징**을 만든다.

**은닉층 학습 = 자동 특징 생성.** 손으로 만든 특징에만 의존하지 않고 문제에 적합한 특징을 자동으로 만드는 것 — 이것이 ANN이 오래 주목받아 온 이유다.

**학습 방법:**

- ANN은 보통 **확률적 경사법(SGD, Section 9.3)** 으로 학습한다. 각 가중치를 목적함수를 개선하는 방향으로 조정.
- 목적함수: 지도 학습에선 라벨 예제에 대한 기대 오차(loss). RL에선 **TD 오차로 가치 함수를 학습**하거나, 기대 보상을 최대화(policy-gradient 등).
- 필요한 것은 각 연결 가중치가 전체 성능에 미치는 영향, 즉 목적함수의 각 가중치에 대한 **편미분 추정**. 이 편미분 벡터가 기울기다.

**역전파(backpropagation):**

- 은닉층 있는 ANN에서 기울기를 구하는 가장 성공적인 방법. **순전파(forward pass)** 로 각 유닛 활성화를 계산하고, **역전파(backward pass)** 로 각 가중치의 편미분을 효율적으로 계산.
- 얕은 망(1~2 은닉층)에선 잘 작동하나, 깊은 망에선 어려움이 있다.

**깊은 망의 어려움과 대응:**

| 문제 | 설명 | 대응 기법 |
| :--- | :--- | :--- |
| 과적합 (Overfitting) | 가중치가 많아 학습 데이터에 과하게 맞고 일반화 실패 | cross validation(조기 종료), regularization, weight sharing, **dropout** |
| 기울기 소실/폭주 | 편미분이 입력 쪽으로 갈수록 급감(학습 느림) 또는 급증(불안정) | 가중치 초기화 개선, **batch normalization**, **residual learning(skip connection)** |

- **Dropout** (Srivastava et al. 2014): 학습 중 유닛을 무작위로 제거 → 다수의 "thinned" 망을 학습하는 효과. 테스트 시 결합으로 일반화 성능 향상.
- **비지도 사전학습** (Hinton et al. 2006, deep belief network): 깊은 층을 한 번에 하나씩 비지도로 학습해 좋은 초기 가중치를 잡은 뒤 역전파로 미세조정.
- **Batch Normalization** (Ioffe & Szegedy 2015): 깊은 층 출력을 미니배치 통계로 정규화 → 학습률 개선.
- **Deep Residual Learning** (He et al. 2016): 블록 주위에 skip connection을 더해 잔차 함수를 학습. 추가 가중치 불필요.

**Deep Convolutional Network (CNN):**

- 이미지처럼 공간 배열된 고차원 데이터 처리에 특화. 뇌의 초기 시각 처리에서 영감(LeCun et al. 1998).
- **합성곱 층(convolutional layer)** 은 여러 **특징 맵(feature map)** 을 생성. 한 특징 맵의 유닛들은 수용 영역만 다를 뿐 **동일한 가중치를 공유(weight sharing)** → 특징이 입력 어디에 있든 같은 특징을 검출.
- 예: 첫 합성곱 층이 6개 특징 맵($28 \times 28$ 유닛), 각 유닛의 $5\times5$ 수용 영역이 겹침 → 각 특징 맵이 단 25개 가중치로 정의됨.
- **서브샘플링 층**은 특징 맵의 공간 해상도를 줄임.
- 특수 구조 덕분에 위의 깊은 층 학습 기법 없이도 역전파만으로 학습 가능. (Ch. 16의 바둑 RL 응용에서 사용)

## 모듈 종합 — 흐름 한 줄 요약

선형 근사의 성패 = 특징 설계. 손으로 만드는 특징은 **coarse coding**(겹치는 수용 영역 → 일반화는 영역 크기·모양이, 변별력은 특징 총수가 결정)과 그 실용적 형태인 **tile coding**(다중 offset 타일링, 일정한 active 특징 수, 이진 → 계산 효율). 특징을 **자동으로 학습**하려면 비선형 근사인 **신경망**으로 가고, 깊은 망은 역전파 + (dropout / batch norm / residual / CNN weight sharing)으로 과적합·기울기 문제를 다룬다.

이로써 "어떻게 상태를 표현할 것인가"라는 함수 근사의 핵심 설계 문제를 손설계~자동학습 양 끝까지 훑었다. 다음 단계는 이 표현 위에서의 **제어(control)** — semi-gradient Sarsa 등 (Module 4).

## 개인 인사이트 / 캡스톤 연결

**1. coarse coding의 "일반화 vs 변별"이 캡스톤 상태 표현 설계의 언어가 된다.**

"초기 일반화는 수용 영역의 크기·모양이, 궁극적 변별력은 특징 총수가 결정한다"(Example 9.3)는 구분이 가장 실용적으로 다가왔다. 캡스톤 navigation에서 로봇 위치를 표현할 때, 인접한 위치끼리 비슷한 가치를 갖도록(일반화) 하면서도 장애물 경계 같은 곳에서는 세밀하게 구분(변별)해야 하는데, 이 두 요구를 "수용 영역 크기"와 "특징 개수"라는 별개의 손잡이로 나눠 조절할 수 있다는 점이 설계 관점에서 유용했다. 막연히 "특징을 잘 만들자"가 아니라, 무엇을 조절하면 무엇이 바뀌는지가 분리되어 보인다.

**2. tile coding의 offset 규칙은 캡스톤에서 바로 시험해볼 후보다.**

다중 타일링을 첫 홀수 변위 $(1, 3, 5, \dots, 2k-1)$ 로 비대칭 offset하고 타일링 수를 $n \ge 4k$ 의 2의 거듭제곱으로 두라는 규칙은, 연속 상태를 다루는 캡스톤에 그대로 적용 가능한 구체적 레시피다. active 특징 수가 항상 일정해서 $\alpha = \frac{1}{n}$ 같은 식으로 스텝 사이즈를 직관적으로 잡을 수 있다는 점도, 하이퍼파라미터 튜닝 부담을 줄이는 실질적 이점으로 보인다. 다만 Isaac Lab의 상태 차원이 커지면 타일 수가 폭발할 수 있어, 신경망과 어느 지점에서 갈릴지는 별도 검토가 필요하다.

**3. 손설계 특징(tile coding) vs 자동 학습(신경망)의 선택 기준이 잡혔다.**

tile coding은 수렴 보장과 계산 효율이 강점이지만 차원이 커지면 특징 수가 빠르게 늘고, 신경망은 특징을 자동으로 만들지만 수렴 보장이 약하고 학습이 불안정하다. 캡스톤이 "정찰(reconnaissance)" 성격임을 고려하면, 초기에는 저차원 상태 + tile coding으로 빠르게 baseline을 세우고, 관측 차원이 커지는 단계에서 신경망으로 넘어가는 단계적 접근이 합리적일 것 같다. 무리하게 처음부터 deep RL로 가지 않는다는 기존 범위 관리 방침과도 맞는다.

**4. DQN 논문(Mnih et al. 2015)이 9.7과 정확히 대응된다.**

3·4주차에 읽었던 DQN 논문에서 게임 화면(픽셀)을 CNN으로 처리해 Q값을 학습한 구조가, 이번 9.7의 두 축 — (1) CNN의 weight sharing으로 위치 불변 특징을 자동 추출, (2) TD 오차로 가치 함수를 학습 — 과 그대로 맞물린다. 당시에는 "딥러닝 + 강화학습"이라는 큰 그림으로만 이해했는데, 이번 모듈을 거치고 나니 그 논문이 9.7의 ANN 함수 근사 + Module 2의 semi-gradient TD를 결합한 구체적 사례였다는 게 분명해졌다. 이론과 대표 논문이 같은 자리에서 만나는 경험이었다.
