# 실험 A_clear: 오른쪽 아래 구석으로 가고 가장 짧게 가

## 입력
- 자연어 명령: "오른쪽 아래 구석으로 가고 가장 짧게 가"
- 가설: 직선에 가까운 단순 경로를 학습하고, `preference=shortest`로 거리 shaping이 들어가 학습 속도가 빨라진다.
- 성공 기준: 학습 후 평균 경로 길이가 16 이하에 가까워진다.

## LLM 파싱 결과
```json
{
  "grid_size": [8, 8],
  "start": [0, 0],
  "goal": [7, 7],
  "obstacles": [],
  "soft_avoid": [],
  "preference": "shortest",
  "interpretation_notes": "오른쪽 아래 구석을 (7,7)로 해석하고, '가장 짧게'는 preference=shortest로 해석"
}
```

해석 노트: 공간 표현과 선호 표현이 모두 명확했다. LLM은 목적지를 `(7,7)`, 경로 선호를 `shortest`로 안정적으로 매핑했다.

## 학습 결과
- 최종 평가 평균 reward: `93.5`
- greedy rollout 평균 경로 길이: `14.0`
- 성공률: `1.0`
- obstacle 진입 횟수: `0`
- timeout 횟수: `0`
- 예시 경로: `(0,0) -> (1,0) -> (2,0) -> (3,0) -> (3,1) -> (3,2) -> (4,2) -> (5,2) -> (5,3) -> (6,3) -> (6,4) -> (6,5) -> (6,6) -> (6,7) -> (7,7)`

## 가설 vs 실제 결과
가설은 충족됐다. 8x8에서 `(0,0)`에서 `(7,7)`까지의 최단 step 수는 14이고, 실제 greedy rollout 평균 경로 길이도 `14.0`으로 정확히 최단 경로에 도달했다. `preference=shortest`가 거리 shaping을 제공하면서 학습 곡선도 빠르게 높은 return 근처에 안정화됐다.

## 발견과 한계
이 케이스는 자연어 표현, 스키마, reward shaping, Q-learning이 가장 잘 맞물리는 기준선이다. 다만 장애물이나 soft constraint가 없기 때문에 "언어가 복잡해졌을 때 의도 보존이 되는가"는 이 실험만으로는 검증되지 않는다.
